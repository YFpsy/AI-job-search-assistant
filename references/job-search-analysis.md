# 当前求职情况分析

## 读取范围

优先读取：

1. `_当前求职状态.md`；
2. `投递记录.xlsx`；
3. `面试记录.xlsx`；
4. 最近或与当前目标有关的岗位分析和面试复盘；
5. 当前使用的简历版本与个人档案。

不要为了分析一次进展默认读取所有录音、全部外部文章或所有历史简历。

## 分析顺序

1. **已确认事实**：统计投递、反馈、面试、结果、岗位方向、渠道和简历版本。
2. **重复情况**：只把至少两次出现的问题列为重复信号，并标明具体记录。
3. **初步假设**：解释可能卡在方向、投递、简历、岗位匹配、面试准备、表达或个人选择的哪里。
4. **还不能判断**：列出样本不足、字段缺失或相互矛盾的地方。
5. **下一步行动**：最多给 3 项，写清直接依据、执行方式和之后观察什么。

## 可用比较

- 不同目标岗位的反馈；
- 不同简历版本的反馈；
- 不同投递渠道的反馈；
- 从投递到反馈、从面试到结果的进展；
- 多场面试反复出现的问题；
- 用户多次提到的工作偏好、消耗点和不能接受的边界。

## 结论边界

- 单次投递、单场面试或短时间无反馈不能证明稳定规律。
- 页面没有记录的数据保持未知，不按零计算。
- 同期改变多个变量时，不能把结果归因到其中一个。
- 外部市场信息只有可靠、当前来源时才能作为背景，不用热点叙事替代个人数据。
- 分析目标是帮助用户决定下一步做什么，不替用户决定接受哪份工作。

完成后先给用户核对关键数字和判断。用户确认后，才把总结与下一步更新到 `_当前求职状态.md`。
