# 投递、岗位分析与简历

## 记录投递

1. 读取 `01_求职过程/投递记录.xlsx`，检查是否已有同一岗位。
2. 信息足够时新增一行；缺少非关键字段可以留空，不阻塞记录。
3. 分配岗位编号，记录使用的简历版本，并在有详细材料时关联岗位档案。
4. 更新后检查行内容、日期类型、状态和路径，不改动已有记录。

## 分析 JD

1. 原样保存 JD，记录来源链接和采集日期；不要把分析混入原文。
2. 分开整理：JD 明确写出、根据 JD 合理推测、仍无法确认。
3. 提取岗位目标、职责、硬性要求、能力特质、协作对象和可能考核内容。
4. 读取个人档案、相关过往经历和选定简历版本，建立逐项对应：
   - 有直接证据；
   - 有可迁移证据；
   - 只有本人判断；
   - 暂无证据。
5. 输出匹配依据、重要缺口、需要澄清的问题和是否值得继续投入的判断框架。
6. 涉及公司现状、行业和业务的当前信息时联网核查并记录来源；没有可靠来源就写无法确认。

## 调整简历

1. 用户先选择目标岗位和要使用的简历版本；原简历不覆盖。
2. 只从个人档案和过往经历中选择真实内容，不为迎合 JD 伪装不具备的能力或价值观。
3. 可以调整顺序、突出相关经历、压缩无关内容、梳理逻辑和语言。
4. 任何新增数据、职责和结果都必须能回溯到原始材料或用户确认。
5. 缺少关键证明时使用明确的待补项并逐个追问，不代填。
6. 生成新版本，并在投递记录中记录实际使用版本；没有投递时不提前写成已使用。

## 分析市场反馈

投递反馈要结合岗位方向、投递渠道、简历版本、投递时间和样本量。先陈述计数与比例，再提出可验证假设。例如：

- 多次投递没有反馈，可能需要检查岗位匹配、简历表达、渠道或市场范围；不能只凭结果认定单一原因。
- 某简历版本获得更多面试，只能作为继续测试的线索，不能直接证明版本本身导致结果。
- 样本较少时优先提出下一轮对照行动，而不是给稳定结论。
